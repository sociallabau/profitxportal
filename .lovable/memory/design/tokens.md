# ProfitX Design System

## Palette (light/default)
- Paper #FBF7F1 — card surfaces (`bg-card`)
- Canvas #E9E1D2 — app background (`bg-background`)
- Ink #161014 — text (`text-foreground`)
- Violet #8536F5 — primary accent, Tier 1 (`bg-primary`, `text-primary`)
- Deep purple #3A1C7A — Tier 2 / Scale (`bg-[hsl(var(--deep-purple))]`)
- Violet tint #E9DEFB — secondary / code-pill bg
- Hairline #ECE3D4 — borders (`border-border`)
- Muted tan #9A8F7C — labels (`text-muted-foreground`)

## Status
- Stop #E2574E · Warn #E8B23E · OK #4FB477

## Typography
- Inter only, weights 500 body / 700–900 structural. No italics.
- Headings: -0.02em tracking. UPPERCASE labels: +0.16–0.2em tracking.

## Components
- Roadmap chip: solid violet/deep-purple, 8–10px radius, white text + translucent code pill.
- Diagnostic row: white pill, hairline border, traffic-light dots.
- No icons/emoji in print-style sections — meaning carried by color + code pills.

## Don't
- New accent hues, gradients, pure black (use ink), emoji in print sections.
