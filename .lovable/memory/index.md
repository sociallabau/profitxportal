# Project Memory

Tokens: paper #FBF7F1, canvas #E9E1D2, ink #161014, violet #8536F5 (Tier 1), deep purple #3A1C7A (Tier 2/Scale).

React + Supabase. Sidebar 240px sticky left. No sign-up — admin creates accounts only.
